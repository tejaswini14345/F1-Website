# F1 Hub 🏁

A Formula 1 themed multi-page website created to present racing-related content, teams, articles, and supporting pages in a visually engaging web experience.

## Project Overview

The site is built as a traditional multi-page frontend and includes pages for:

- Home
- About
- Blog
- Blog details
- Portfolio / content sections
- Services
- Team
- Contact

## Tech Stack

- HTML5
- CSS
- JavaScript
- Responsive web design assets

## Repository Structure

```text
F1-Website/
├── index.html
├── about.html
├── blog.html
├── blog-details.html
├── contact.html
├── portfolio.html
├── portfolio-details.html
├── services.html
├── team.html
├── forms/
└── assets.zip
```

## What This Project Demonstrates

- Multi-page website structure
- Frontend layout and navigation
- Responsive content presentation
- Organizing static web pages and reusable design assets

## Run Locally

Clone the repository and open `index.html` in a browser. For a better local-development experience, serve the directory with a simple local web server or a VS Code extension such as Live Server.
